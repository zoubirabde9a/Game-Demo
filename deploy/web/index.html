Game Demo

An online arena fighter. Sword, fireball, dash and shockwave against other players, with monsters roaming the map.

Download for Windows

Windows 10 or 11. The download is the launcher; it fetches the game (about 10 MB).

Installing

  1. Run GameDemo.exe. It installs the game in your user folder and adds a Game Demo shortcut to the desktop and Start menu.
  2. The game opens and joins the server.

Windows may say it protected your PC, because the launcher is not signed yet. Click More info, then Run anyway.

Updates

Start the game from the shortcut. When we put out a new version, the launcher downloads it while you play and restarts the game on it, usually within 20 seconds.

Controls

  • Z Q S D move, Space jump, Alt dash
  • Left click: walk there, or fireball a monster or player
  • Right click: sword. E: shockwave. Hold Tab: scoreboard
